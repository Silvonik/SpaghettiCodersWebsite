## The Club
Spaghetti Coder is a technology/coding club led by a teen located in Dublin, Ireland for teens aged 13-18, we make games, websites, electronics, 3D prints, and whatever else we come up with!
We host weekly meetings where we meet up, build projects, present our projects, and have fun!
